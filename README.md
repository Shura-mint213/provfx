# ✅ **Уровни блокировок (5 уровней)**

## 🔵 **Level 0 — Нет блокировки**

Запись в таблице отсутствует
→ Оба пользователя могут взаимодействовать свободно.

---

## 🟡 **Level 1 — Частичная блокировка (мягкий mute)**

❗ Пользователь сам ставит другому.

Ограничивает:

* ❌ Нельзя писать сообщения (когда появятся)
* ❌ Нельзя приглашать в проект
* ✔ Можно видеть профиль
* ✔ Можно видеть в галерее
* ✔ Можно приглашать в обратную сторону (второй пользователь может пригласить)
* ✔ Можно быть участником одного проекта

Такой блок нужен, когда человек просто не хочет получать приглашения от конкретного пользователя.

---

## 🟠 **Level 2 — Жёсткая блокировка (Полный блок от пользователя)**

❗ Ставит обычный пользователь.

Ограничивает больше:

* ❌ Нельзя писать
* ❌ Нельзя приглашать
* ❌ Нельзя видеть профиль
* ❌ Нельзя видеть в галерее
* ❌ Нельзя взаимодействовать нигде

**Полный пользовательский бан** — как в соцсетях.

---

## 🔴 **Level 3 — Админ-блок (частичный системный бан)**

❗ Ставит только администратор.

Ограничения:

* ❌ Пользователь не может писать
* ❌ Не может вступать/создавать проекты
* ✔ Может войти
* ✔ Может просматривать проекты
* ✔ Может быть участником уже существующего проекта

Нужно когда пользователь ведёт себя плохо, но его нельзя выкинуть полностью.

---

## ⛔ **Level 4 — Админ-блок полный (бан аккаунта)**

❗ Ставит только администратор.

Ограничения:

* ❌ Полностью запрещён вход в систему
* ❌ Ничего не видно, ничего нельзя делать
* Страница логина сообщает: “Ваш аккаунт заблокирован”

Этот уровень нужен почти во всех системах.

---

# 🧩 **Итого: 5 уровней**

| Уровень               | Кто ставит   | Ограничения                       |
| --------------------- | ------------ | --------------------------------- |
| **0**                 | —            | нет блокировки                    |
| **1** частичный       | пользователь | нет сообщений, нет приглашений    |
| **2** полный          | пользователь | скрытие везде, нет взаимодействия |
| **3** частичный админ | админ        | ограничения по действиям          |
| **4** полный админ    | админ        | запрет входа                      |

---

# 🔧 ЛОГИКА БЛОКИРОВОК (универсальная)

## Пользователь → Пользователь:

```
1 = частичная
2 = полная
```

## Админ → Пользователь:

```
3 = ограниченный вход
4 = полный бан
```
